Tesla FSD Tracker 🇨🇦 Canada
Full Self-Driving — Included Package finder

Find a Tesla that already includes FSD.

Most sellers bury it. This tracker scans Canadian listings on AutoTrader, CarGurus, Kijiji Autos, Facebook Marketplace and dealer sites, then checks the two places FSD actually shows up:

1
The software-screen photo
Controls → Software must read “Full Self-Driving Capability — Included package” (not “Subscription” or a trial). The same screen shows the computer: FSD Computer 3 = HW3, Computer 4 / AI4 = HW4.
2
The listing description
Text is searched for “Full Self-Driving”, “FSD included”, “Enhanced Autopilot”, “Acceleration Boost” and “SC01” (free unlimited Supercharging).
⚠️ Preview data: the listings marked Demo are examples showing how verified results will look. The automatic scanner (GitHub Action in this repo) replaces them with real Canadian listings on its first successful run. Use the Live search buttons below for real cars right now.
